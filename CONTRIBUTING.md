# Contributing

Keep analysis changes distinct from website presentation changes. Run `npm test` for website edits. For R edits, install the app dependencies and run the relevant scripts in `tests/`, then check an appropriate real dataset and record input identifiers, settings and package versions. Do not describe synthetic explorer data as experimental evidence.

For bug reports, provide the GSE/GPL, assay, organism, group sizes, exact error and `sessionInfo()`. Remove private sample information. Include a minimal reproducible example when possible.

Preserve keyboard access, table alternatives and reduced-motion behavior. No fabricated performance numbers, endorsements or passing-test badges.
