03 / KEEP THE CONTEXT

Beyond a ranked gene list.

The details that make
an analysis easier to follow.

[ A ]

Groups that stay attached.

Filter metadata, assign selected or filtered samples, and keep membership keyed to GSM accessions as you sort and switch platforms.

[ B ]

Annotation you can inspect.

Review symbol coverage and recover available annotation from source metadata or optional organism databases. Missing values stay visible.

[ C ]

A record of the decisions.

Export full results as Excel or TSV, sample metadata before analysis, and a generated R script for reviewing the workflow.
