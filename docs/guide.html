Start with the app

Extract the app download, open GEOContrast.Rproj in RStudio, and run these commands from that folder:

source("install_packages.R")
shiny::runApp()

R, an internet connection for installation and GEO downloads, and compatible CRAN/Bioconductor packages are required. The installer installs missing dependencies; versions are not locked. Optional local human, mouse and rat annotation databases: source("install_annotation_dbs.R").

The supplied R interface retains its original GEO2R — Multi-Species title. This release adds the GEOContrast repository and website identity while preserving the analysis source.

Define the comparison

Enter a GSE accession, choose an organism and platform, then assign samples to groups using metadata, selected rows or filtered rows. Filtering a table does not itself assign samples. Group membership follows GSM accessions.

Use at least two matched samples per analyzed group and at least four in total. Review the membership before modeling. In the two-group RNA-seq workflow, the first-defined group is the numerator and the second is the reference. Verify labels and the generated script for every comparison.

Export sample metadata before analysis to preserve your grouping decisions.

Follow the data

InputEngineModel behavior
Microarray Series MatrixlimmaOptional log2 transformation, between-array normalization and vooma. Moderated t-tests for two groups; overall moderated F-tests for three or more.
Validated integer RNA-seq countsDESeq2Two groups: Wald test with poscounts size factors. Three or more: overall LRT with default ratio size factors; selected pairwise plots use Wald tests.

RNA-seq accepts non-negative integer raw counts matched to GSM samples. It rejects TPM, FPKM, CPM and log-normalized expression as raw counts. Counts may come from NCBI-computed data when available, supplementary files or an upload.

The default count prefilter requires counts of at least 10 in at least the smallest group's number of samples. Independent filtering is enabled; the selected alpha matters. Overall multi-group RNA-seq tables do not have a single fold-change coefficient.

The source includes a “GEO2R parity” mode. Exact equality with official GEO2R is not established; inputs, package versions, annotations and settings can differ.

Respect the design

  • One organism per model. Multi-species support means selecting the organism for an analysis, not pooling species.
  • Multiple microarray GPLs: view, group and export samples, but choose a single GPL for limma.
  • Multiple RNA-seq GPLs: one validated count matrix must cover all selected platforms. The extended design uses ~ Platform + condition and must have full rank. Confounded platform and condition effects are blocked.
  • Mixed assays: joint differential expression is blocked. Analyze assay types separately.

Keep identifiers honest

Annotation is normalized into GeneID, Symbol and Description fields, with recovery from available inputs, GEOquery metadata, human annotation caches and optional organism databases. Version-stripped Ensembl matching is supported. Coverage depends on the dataset and annotation source.

Missing annotations remain blank. The interface reports coverage; absence of a symbol is not evidence that a feature is biologically unimportant.

Take the context with you

The R app provides volcano, mean-difference, adjusted-P histogram, PCA and gene-profile plots. These are the supplied Shiny plot views; the rotatable 3D landscape belongs to this website demonstration.

  • Sample workbooks capture samples and relevant filtered/selected subsets.
  • The results table shows the top 250 ranked features by default.
  • Dedicated Excel and TSV exports contain full results. Excel Options records analysis settings and provenance fields.
  • A downloadable generated R script helps inspect the workflow; review source-specific loading and settings before relying on it for a rerun.

Understand the browser demonstration

The explorer generates 320 deterministic synthetic features and 12 illustrative values per feature. Its adjusted P-values use Benjamini–Hochberg correction over the full synthetic feature set. The simulated P-values are not inferred from the displayed profiles.

Changing thresholds filters or recolors existing results; it does not refit a statistical model. Reversing the contrast flips effect signs while retaining adjusted P-values. Summary counts describe all 320 features; the table and export follow the current search and passing-feature filter.

Drag to rotate, use arrow keys to orbit and +/− to zoom, or select the Results tab for a table. Rotation is opt-in. Synthetic exports are explicitly labeled. No user data is uploaded by this demo.

When a run needs attention

Package installation or GEO retrieval fails

Check R/Bioconductor compatibility, network access and the original error in the R console. GEO data availability differs between accessions.

Counts do not match samples

Check column identifiers against GSM accessions, the selected platforms, group assignments and integer-count validation. Do not round normalized data into counts.

A platform-adjusted model is blocked

Review whether each condition is represented across platforms. A confounded design cannot distinguish biological and platform effects.

This presentation release preserves the supplied R code. R execution and real-dataset validation were not available during packaging. Use the included R regression scripts in a configured environment.
